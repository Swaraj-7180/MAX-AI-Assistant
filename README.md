# MAX — AI Desktop Voice Assistant

A Python-based intelligent desktop voice assistant with Groq AI, 
Jarvis-style HUD, and comprehensive system automation.

## Features
- 🤖 AI Brain (Groq/LLaMA 3.3 70B) with witty personality
- 🎤 Voice Recognition (Google STT, en-IN)
- 🔊 Neural TTS (Microsoft edge-tts NeerjaNeural)
- 💻 System Automation (15+ apps, volume, power)
- 📋 Task & Reminder Management
- 💬 WhatsApp & Gmail Integration
- 🧠 Second Brain Memory System
- 🖥️ Jarvis-Style Animated HUD
- 🗂️ File Search & Organizer

## Setup
1. Clone repo: `git clone https://github.com/YourUsername/MAX-AI-Assistant`
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Groq API key in `ai_brain.py`
4. Add Gmail app password in `messaging.py`
5. Run: `python main.py`

## Tech Stack
Python 3.10 | Groq API | LLaMA 3.3 70B | Google STT | 
edge-tts | CustomTkinter | pywhatkit | pygame
